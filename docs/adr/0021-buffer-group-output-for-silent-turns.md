# Buffer group output for Silent Turns

Group Chat Turns buffer automatic Reply Delivery until the Turn settles so a structured `clawchat_no_reply` No-Reply Completion can terminate the Turn and suppress every assistant, thinking, and tool message while remaining auditable in Pi context. The exact `[SILENT]` marker remains only as a compatibility fallback, with the observed missing-closing-bracket form `[SILENT` suppressed narrowly so an almost-correct marker never leaks into the group. This deliberately delays non-silent group output but preserves each Output Mode's content and ordering; direct chats remain immediate, direct Agent mentions reject both silent paths, typing remains visible, aborted buffers are discarded, and already completed explicit sends cannot be retracted.
